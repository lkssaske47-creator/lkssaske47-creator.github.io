PPSSPP Mod: Adding PS5 Button Icons to PSP Games

If you're playing PSP games on PPSSPP and tired of seeing Xbox A/B/X/Y prompts when you're using a DualSense, you can swap them for PS5 □ △ ○ × icons. PPSSPP doesn't have a built-in "force PS5 icons" toggle, but it supports texture replacement packs.

1. How PPSSPP Handles Button Icons

PPSSPP renders the on-screen button prompts from textures inside the game. To change them, you use a texture replacement pack. Each pack needs a folder named exactly after the game's serial number, like ULUS10308, and a textures.ini file inside.

2. Installing the BUTTONS

  1. Download the zip pack.
  2. In Zarchiver go to your downloads, locate the zip, extract it and paste it in your PSP root folder, the buttons will be replaced automatically.

3. Enabling Texture Replacement

  1. Open PPSSPP > Settings > Tools > Developer Tools.
  2. Enable Replace Textures.
  3. Launch the game. The PS5 icons should now show up in menus and prompts.

4. Tips

  • Game ID: Right-click the game in PPSSPP's list and check the code next to the name.
  • Performance: If you get lag, make sure "Save New Textures" is OFF.
  • Pack compatibility: A pack made for ULUS10308 won't work on the PAL version ULES-00999.
